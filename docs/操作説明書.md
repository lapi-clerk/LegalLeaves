# LegalLeaves 操作説明書

**e裁判の書類を、軽っと整える。**

バージョン 5.2.5 ／ 2026年11月

---

## 1. これは何をするソフトですか

裁判所の電子提出システム（mints）へ出すファイルを整えるツールです。
これまで手作業でしていた次のことを、まとめて行います。

- **提出用の名前に変える**（甲001_○○.pdf のように）
- **PDFに残った作成者名・事務所名などの情報を消す**
- **証拠番号のスタンプを押す**
- **枝番に分かれた証拠を1つのPDFにまとめる**
- **証拠説明書の下書きをWordで作る**

Wordや画像で受け取った資料も、提出できるPDFに変換します。

> **出力の最終確認は必ず弁護士が行ってください。**
> 特に証拠説明書の立証趣旨は「下書き」です。そのまま提出できるものではありません。

## 2. 使う前に

### 動作するパソコン

- **Windows 10 または 11**
- Word・Excel・PowerPoint を読み込む場合と、証拠説明書をPDFにする場合は、
  **そのパソコンに Microsoft Office が入っている必要があります**
  （PDFへの変換に使います。無料の LibreOffice でも動きます。https://ja.libreoffice.org/ から入手できます）

### 入れ方（インストール）

インストーラは、GitHub のダウンロードページ（**https://github.com/lapi-clerk/LegalLeaves/releases**）から入手できます
（いちばん上の版の「Assets」にある `LegalLeaves-Setup-○.○.○.exe`）。

1. 入手した `LegalLeaves-Setup-○.○.○.exe`（○.○.○ は版の番号）をダブルクリックします
2. 「**インストール**」を押すと、すぐに入ります（**管理者の権限は必要ありません**。あなたのユーザーにだけ入ります）
3. 最後の画面で「**デスクトップにショートカットを作る**」を選べます（最初はチェックが入っています）。
   スタートメニューには必ず **LegalLeaves** が入ります。次回からはここから起動します
   （選んだ内容は覚えておき、次に更新するときも同じ状態で始まります）

スタートメニューには「**LegalLeaves 操作説明書**」も入ります。

**新しい版に更新するとき**は、新しいインストーラをそのまま実行してください。メモや設定は消えません。

### 初回の実行で青い警告が出ます（正常です）

インストーラをダブルクリックすると、次のような画面が出ることがあります。

> **Windows によって PC が保護されました**
>
> Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました

これは「**このソフトに有料の電子署名が付いていない**」ことによる警告で、
ウイルスが見つかったという意味ではありません。個人や小規模で作られたソフトでは普通に出ます。

**通し方**

1. 「**詳細情報**」をクリック
2. 下に出てくる「**実行**」をクリック

一度通せば、次回以降は出ません。

> **心配なときは実行前に確認できます。** ダウンロードページの各版の説明に、インストーラの
> 「SHA-256」という64桁の英数字を載せています（人から受け取った場合は、渡した人に別の経路で教えてもらってください）。
> インストーラのあるフォルダで PowerShell を開き、次を実行します（○.○.○ は入手した版の番号に置き換えてください）。
> 表示された値が一致すれば、公開したものと中身が同じであることが確認できます。
>
> ```
> Get-FileHash .\LegalLeaves-Setup-○.○.○.exe -Algorithm SHA256
> ```

## 3. 大事な前提（先に読んでください）

このソフトは、**AI**（ChatGPT・Claude・Gemini 等）と**役割を分担**して動きます。

| | やること |
|---|---|
| **AI** | どのファイルが何の証拠かを読み取り、証拠番号・標目・立証趣旨の下書きを作る |
| **LegalLeaves** | ファイル名の照合、PDFの編集、メタデータ削除、証拠説明書の生成 |

つまり、**手順の途中で、あなたがAIに証拠ファイルを添付して送ります**。

> ### 守秘義務に関わる注意
>
> - 添付したファイルは**外部のAIサービスに送信されます**
> - **事務所で認められたサービス・アカウント**を使ってください
> - **入力内容が学習に使われない設定**（ビジネスプラン等）になっているか確認してください
> - ソフトがコピーするプロンプトには「事務所の書き方メモ」の内容も含まれます

**LegalLeaves は、ファイルの中身や作業の内容を外部へ送りません。** ファイルの編集はすべて LegalLeaves を入れたパソコンの中で行われ、
ファイルが自動で送信されることはありません。AIへ送るかどうかは、あなたの操作次第です。
（今の版は外部と通信しません。将来「新しい版が出たことのお知らせ」を足す場合も、通信は新しい版があるかどうかの確認だけにとどめます）

## 4. 基本の流れ（5ステップ）

画面の上に「1 読み込み → 2 照合 → 3 確認 → 4 出力 → 5 完了」と出ます。
進んだところまでは、クリックで戻れます。

### ステップ1 ── 読み込み

**① 提出したいファイルを入れる**

画面左の枠に、ファイルを**ドラッグ＆ドロップ**します。「**ファイルを選択**」ボタンでも構いません。
PDF・画像・Word・Excel・PowerPoint・音声・動画に対応しています。

**② AIにファイルを渡す**

1. 画面右の「**AI用プロンプトをコピー**」を押す
2. AI（ChatGPT・Claude・Gemini 等）を開いて**貼り付ける**
3. **ファイルを添付**して送信する
4. 添付できる数に上限があるAIでは、**数回に分けて送り**、最後に「**完成**」とだけ入力する

**③ AIの答えを貼り戻す**

AIが出したJSON（`{` から始まる長い文字列）をコピーし、
「**クリップボードから貼り付け**」を押すか、下の欄に直接貼り付けます。

うまく受け取れると「**✓ 整理データを受け取りました**」と表示されます。

**④「照合して進む」を押す**

> **少しの証拠を後から追加するときは、AIを使わずに進めます**
>
> ファイル名を「甲1の2_領収書.pdf」のように**号証番号から始めておく**と、
> 「**AIを使わずに進む**」で番号を決めて確認画面へ進めます（本書 6. を参照）。

> **事務所独自の書き方がある場合**
>
> 「**事務所の書き方メモを編集**」に立証趣旨の書き方などを書いておくと、
> 次回からプロンプトの末尾に自動で足されます。一度書けば消えません。

### ステップ2 ── 照合

ファイルとAIのデータが正しく対応しているかを、ソフトが自動で突き合わせます。

**問題がなければ、この画面は出ずに確認画面へ直接進みます**（確認画面の上に「照合では問題がなかったため、確認画面へ進みました」と出ます）。
読み込み忘れ・AIへの送り忘れ・証拠説明書との食い違い・AIからの注意などがあるときだけ、この画面で止まります。
飛ばした後でも、画面上の「照合」を押せば中身を見られます。

- 上に「読み込んだファイル」「AIデータとの一致」「**要確認**」「削除予定のPDF情報」の数が出ます
- 確認が必要なものは**オレンジのバナー**で知らせます
- 対応が付かなかったファイルは、手動で割り当てられます

問題なければ「**確認へ進む**」。

### ステップ3 ── 確認（いちばん大事な画面です）

ファイルを1件ずつ選んで、内容を確かめます。

**確かめる項目**

| 項目 | 説明 |
|---|---|
| **種類** | 主張系／証拠説明書／証拠／関連事件の申立／その他 |
| **文書名**（証拠なら標目） | 証拠説明書に載る名前 |
| **提出用ファイル名** | **この名前で保存されます**（枝番を1つのPDFにまとめるときは、番号と標目から作ります） |
| **証拠番号** | 例: 甲001。枝番は 甲3-1 のように書きます |
| **PDF情報** | 作成者名などを「削除／維持」で選べます |

- 中身を見たいときは「**元ファイルを見る**」でその場に表示できます（Word等は別アプリで開きます）。
  **画面が広いとき**（全画面など）は、選んだファイルのプレビューが右側に**自動で開きます**。
  作業の途中で窓を広げたときも開き、狭めたときは閉じます。
  「プレビューを閉じる」を押すと、そのあとは自動では開きません。ボタンで開け閉めしたあとは、
  窓の大きさを変えても、そのときの状態のままです
- **写真やスキャンが横向き・逆さまのとき**は、プレビューの上のボタンで向きを直します。
  「**↺ 左に90°**」「**↻ 右に90°**」「**180°**」を押すと、プレビューもその向きに変わります。
  「**元に戻す**」で元の向きに戻ります（出力前のプレビューにも同じボタンがあります）。
  複数ページのPDFで回るのは、番号を押すページ（ふつうは1ページ目）です
- 左の一覧は、要確認のものがあると、最初は**要確認のものだけ**を表示します（画面が広いときは最初から全件）。
  **並べ替えや挿入をするときは「全件を表示」**を押してください
- **証拠番号を書き換えると、提出用ファイル名の先頭の番号も合わせて変わります**。
  逆に、提出用ファイル名の番号を書き換えても証拠番号は変わりません（入力の途中で番号が動かないように）。
  食い違うと欄の下に「ファイル名の番号（甲3）と証拠番号（甲4）が違います」と出るので、
  「**証拠番号を甲3にする**」か「**ファイル名を甲004で始める**」のどちらかを押して合わせます。
  知らせは、Enter を押すか欄を離れたときに出ます（入力している間は、出ている知らせが薄くなり、確定すると更新されます）。
  食い違いのあるファイルは、左の一覧にも「**要修正**」（オレンジ）・「**エラー**」（赤）の印が付きます。
  片方が番号として正しくない（「甲0」、ファイル名に番号が無い等）ときは、正しいほうに合わせるボタンだけが出ます。
  両方とも正しくないとき・欄が空のときは赤のエラーで知らせるので、証拠番号やファイル名を入力してください
  （ファイル名だけが空なら「ファイル名を甲004で始める」「ファイル名を標目から作る」で作り直せます。
  両方とも正しくないときは「**最初の値に戻す**」で、そのファイルだけ確認画面を開いたときの値に戻せます）
  書き換えで途中の番号が空いたとき（甲3を甲4にした等）は、空いた番号が「**後で追加予定**」の空き枠として一覧に出ます
  （証拠説明書には空行で出ます。要らなければ × で消せます）
- 読み込んだファイルの番号に抜けがあるとき（甲1 と 甲4 だけ等）は、その位置に
  「**甲2・甲3 は今回のファイルにありません**」と薄く表示します。前に提出済みの番号ならそのままで構いません。
  あとで出す予定なら「**後で追加予定にする**」を押すと空き枠になります（証拠説明書に空行が出ます）
- **種類を「証拠」以外に変えると、証拠番号とスタンプは自動で外れます**
- 証拠説明書を作るときは、証拠ごとに「**証拠説明書の欄**」を開いて、作成者・作成日（写真などは撮影者・撮影日）・
  原本／写し・立証趣旨を書き込めます。書いた内容は証拠説明書の下書きに入り、空欄は ●● のままです
  （AIの整理データに入っていた値は、最初から入っています）
- 迷ったら「**AIの値に戻す**」で元に戻せます。全部やり直すなら「**編集をすべて取り消す**」

**証拠番号のスタンプ**

- 押す／押さないを選べます。すでに番号が押された証拠一式なら「**すべて既に押印済み**」で一括設定
- mints に提出すると、裁判所が1ページ目に**タイムスタンプの帯**を付けます（多くはページの上部です）。
  そこに重なりそうな位置には警告が出るので、**ワンクリックで帯の下へ移動**できます

**あとで枝番を足す予定のとき（甲1の1にする）**

今は甲1だけれど、あとで甲1の2を追加する予定がある場合は、一覧で甲1を選び、
下の「**甲1の1にする**」を押します（ボタンの名前には、選んでいる証拠の番号が入ります）。
甲1が「甲1の1」になり、「甲1の2」の空き枠ができます。
甲1の2を実際に追加するときの手順は、本書 6. を参照してください。

**1つのPDFに複数の枝番が入っているとき（ページで枝番に分ける）**

請求書と領収書をまとめて1つのPDFにスキャンした場合など、1つのPDFを枝番ごとに分けられます。

1. 一覧でその証拠を選び、下の「**ページで枝番に分ける**」を押します
   （号証番号が付いた、2ページ以上のPDFのときに出ます）
2. 各枝番のページを `1-3, 4-5` のように入力して「**分ける**」を押します
   （1〜3ページ目が の1、4〜5ページ目が の2 になります。1ページだけの枝番は `3` のように書きます）
3. 一覧に「甲3の1（1〜3ページ目）」「甲3の2（4〜5ページ目）」と分かれて並びます。
   **2つ目以降の枝番の標目は、同じ名前で始まるので直してください**

- AIが区切りを見つけていれば、入力欄に最初から入っています。確認メッセージに区切りと根拠
  （証拠説明書・準備書面の引用・書式の変わり目など）が書かれているので、確かめてから「分ける」を押してください
- ページの抜けや重なり、全ページ数との食い違いがあると、エラーで止まります。
  **1ページのずれは見分けられない**ので、出力のプレビューで各枝番の先頭ページを確かめてください
- 番号は各枝番の**先頭ページにだけ**押されます。出力時は1つのPDF（例 `甲003_1～2_請求書.pdf`）にまとまります
- 分け方を間違えたら「**ページの分け方を元に戻す**」で1つのPDFに戻せます

**「要確認」のチェック**

オレンジの「要確認」が付いたファイルは、**チェックを入れて確認済みにしないと先へ進めません**。
まとめて片付けるボタンもあります。

済んだら「**出力前チェックへ**」。

### ステップ4 ── 出力

画面の上に「**出力前チェック**」が出ます。次のような食い違いがあると、一覧で知らせます
（押すと確認画面のその証拠へ戻ります。直さずにそのまま作成することもできます）。

- 提出用ファイル名の番号と、押す番号が違う（例: `甲003_写真.pdf` に「甲第4号証」が押される）
- 枝番が重なっている・飛んでいる・枝番のあるものと無いものが混ざっている
- 証拠なのに証拠番号が無い／同じ名前のファイルが2つできる

ファイル名の番号の食い違いには、行の右に「証拠番号を○にする」「ファイル名を○で始める」のボタンが出て、
確認画面に戻らずにその場で合わせられます。

食い違いが無ければ「番号とファイル名の食い違いはありません。」と1行だけ出ます。

1. 「**フォルダを選ぶ**」で保存先を指定します（フォルダのドラッグ＆ドロップでも可）
2. 「**専用サブフォルダを作成**」がオンだと、「提出用ファイル」フォルダにまとめて出力されます
3. 「**作成前にプレビューで確認する**」をオンにしておくと、書き出す前に実物を見られます（**推奨**）
4. 証拠がある場合は「**証拠説明書（下書き）も作成する**」を選べます
5. 「**提出用ファイルを作成**」を押す

**プレビューが出たら**

- スタンプを**ドラッグでそのまま動かせます**。向き（↺ ↻ 180° のボタン）・押印の有無もその場で変えられます
- 証拠説明書を作る設定で、立証趣旨が1つでも入っていれば、一覧のいちばん下の「**証拠説明書（下書き）**」で
  書く内容を表で確かめられます（見やすくした表です。実際の書式は作成される Word で確かめてください）
- 1ページ目には、裁判所のタイムスタンプが付く位置が**半透明で表示**されます。**重ならない位置**へ
- よければ「**承認して書き出す**」。ここで初めてPDFに焼き込まれます

同じ証拠番号で枝番に分かれたファイルは、**1つのPDFに自動でまとまります**。

### ステップ5 ── 完了

できたファイルの一覧が、それぞれの大きさと一緒に出ます。「**フォルダを開く**」ですぐ確認できます。

一覧の上に**合計の大きさ**が枠で出ます。mints は**一度のアップロードが 200MB まで**なので、

- 合計が 200MB 以内なら「上限以内です」と出ます
- 合計が超えるときは「何回かに分けて（目安 ○回以上）」と出ます。分けてアップロードしてください
- **1つで 200MB を超えるファイル**は赤で示します。そのままでは出せないので、分けるか小さくしてください

（プレビューの一覧にも、ファイルごとの大きさが出ます）

---

## 5. もう一つの使い方 ── 名前とメタデータだけ整える

**すでに押印まで終わっている**書類や、**単に作成者名を消したいだけ**のときは、
ステップ1の上にある「**リネーム＋メタデータ削除（スタンプ・結合なし）**」にチェックを入れます。

**このモードは AIのデータが無くても使えます。**
元のファイル名のままメタデータだけを消し、Word等はPDFに変換します。

## 6. 後から証拠を追加するとき

後から証拠を追加するときは、**追加する分のファイルだけ**を読み込めば足ります（前回の分を読み込み直す必要はありません）。
証拠説明書も、読み込んだ分だけで作られます。

### おすすめ: AIを使わずに進む（少しの追加のとき）

1. 追加するファイルの名前を、**号証番号から始まる名前**にします
   （例: `甲1の2_領収書.pdf`・`甲5_写真.jpg`。「甲1-2」「甲1_2」でも構いません）
2. LegalLeaves を起動し、そのファイルを読み込みます
3. 「**AIを使わずに進む**」を押します（AIの整理データは貼りません）
4. 確認画面で、次を確かめます
   - 証拠番号と枝番（ファイル名から自動で入ります）
   - 証拠説明書の標目（ファイル名の番号より後ろ＝「領収書」が入ります。必要なら直します）
   - 提出用ファイル名（例: `甲001_2_領収書.pdf`）
5. あとは普段どおり、出力 → プレビュー → 書き出し です（番号は「甲第1号証の2」と押されます）

- ファイル名に号証番号が無いファイルは「要確認」になります。証拠なら番号を入れ、
  証拠でなければ種類を選んで確認済みにしてください
- 証拠説明書を作る場合、作成者・作成年月日・立証趣旨は、確認画面の「**証拠説明書の欄**」で書き込めます。
  書かなかった欄は「●●」のまま残るので、生成された証拠説明書（Word）で直してください

### もう一つの方法: 追加分だけ AI に渡す

追加が多いときや、証拠説明書の作成者・立証趣旨の下書きも AI に作らせたいときは、
**追加分のファイルだけ**をいつもの手順で AI に渡します。

1. 追加するファイルの名前を、上と同じく**号証番号から始まる名前**にしておきます
   （プロンプトで「ファイル名の号証番号を優先する」よう指示しているので、AI が番号を振り直しにくくなります）
2. 「**AI用プロンプトをコピー**」→ AI に貼り付け、**追加分のファイルだけ**を添付します
3. 返ってきた整理データを貼り付けて、「**照合して進む**」 → あとは普段どおりです

> **前回の分は読み込み直さなくて構いません。** 一度提出した証拠をもう一度処理すると、
> 番号が二重に押されたり、同じ号証が二度提出されたりするおそれがあります。

## 7. 知っておいてほしいこと

### 消える情報・消えない情報

**消える**（事務所名・個人名が入りうる項目）

タイトル／作成者／件名／キーワード／作成アプリ／出力アプリ／XMP（Wordが埋め込む詳細情報）

**消えない**

作成日時・更新日時／PDF内のJavaScriptや自動実行の設定／埋め込みファイル・添付／外部リンク／入力フォーム

> **本文に書かれた氏名・事務所名は消えません。**
> 見えている文字や画像の中身は、目視で確認してください。

### スマートフォンの写真の向き

スマートフォンの写真は、画素は横向きのまま保存し、「縦に持って撮った」という**向きの情報**を付けて記録することがよくあります。
LegalLeaves は、この向きの情報を**エクスプローラーやブラウザと同じように**読んで、見えているとおりの向きでPDFにします。
向きを推測して変えることはしません。

- エクスプローラーで横向きに見える写真（机に置いた書類を真上から撮ったときなど、向きの情報が実際とずれることがあります）は、
  PDFでも横向きになります。確認画面やプレビューで**回して**直してください（回した分は、見えている向きに上乗せされます）
- AIの整理データで回転が指定されていれば、それも見えている向きに上乗せされます

### Word文書をそのままPDFにすると危険なことがあります

Word（.docx）を読み込むと、確認画面の「PDF情報」に
**「保存時に個人情報を削除」が未設定かどうか**を表示します。

未設定のまま**Wordで直接PDF化して提出すると、作成者欄にパソコンのユーザー名が入る**おそれがあります。
**LegalLeaves を通して出力すれば自動で消える**ので、なるべくこちらを経由してください。

### パソコンに保存されるもの・されないもの

**保存されるもの**（LegalLeaves を入れたパソコンの中だけ。クラウドには送信しません）

事務所の書き方メモ／最近使ったフォルダの履歴／画面の設定

**保存されないもの**

読み込んだファイルやAIの整理データ（**作業内容そのものは終了時に消えます**）

### やめるとき（アンインストール）

Windows の「**設定 → アプリ → インストールされているアプリ**」で **LegalLeaves** を選び、
「**アンインストール**」を押します（ほかのアプリと同じ消し方です）。

途中で「**事務所の書き方メモ・最近使ったフォルダの履歴・画面設定も削除しますか？**」と聞かれます。

- 「**はい**」… すべて削除します。**LegalLeaves を入れたパソコンに何も残りません**
- 「**いいえ**」… メモ・履歴・設定だけ残します。あとで入れ直したときに引き継がれます

アプリ本体・ショートカット（デスクトップ・スタートメニュー・タスクバーにピン留めしたもの）・
作業用の一時ファイルは、どちらを選んでも消えます。
読み込んだ元ファイルや、出力済みの提出用ファイルには影響しません。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 起動時に青い警告が出る | 正常です。「詳細情報」→「実行」（本書 2. を参照） |
| インストール・アンインストールで「起動中です」と出る | LegalLeaves を終了してから「再試行」を押してください |
| 画面が出ない・真っ白のまま | 画面の表示に Windows の「Microsoft Edge WebView2」を使います（Windows 11 と、ほとんどの Windows 10 に入っています）。入っていない場合は、Microsoft のサイトから「WebView2 ランタイム」を入れてください |
| Word・Excelを入れたのに進めない | そのパソコンに Microsoft Office（または LibreOffice）が入っているか確認してください |
| AIのデータを貼ったらエラーになる | JSON全体（`{` から `}` まで）がコピーできているか確認してください。途中で切れていることが多いです |
| AIがファイル名を読み違える・違う証拠番号を振ってくる | 読み込み画面の「**ファイル名リストをコピー**」を押し、プロンプトと一緒にAIへ貼り付けてください（ファイル名の一覧を渡すと、読み違えにくくなります） |
| 「照合して進む」が押せない | ファイルとAIの整理データの両方が必要です（AIを使わない場合は「AIを使わずに進む」、リネームのみモードならファイルだけで進めます） |
| 並べ替え・挿入ができない | 一覧が要確認のものだけの表示になっています。「全件を表示」を押してください |
| 「ページで枝番に分ける」が出ない | 号証番号が付いた2ページ以上のPDFのときだけ出ます。刑事の弁号証・検号証は枝番を使わないので出ません |
| 「出力前チェックへ」が押せない | オレンジの「要確認」が残っています。チェックを入れてください |
| 写真が横向き・逆さまになる | エクスプローラーでの見え方と同じ向きになります。プレビューの上の「↺ 左に90°」「↻ 右に90°」「180°」で直してください（本書 7. を参照） |
| 出力前チェックに食い違いが出る | 押すとその証拠に戻ります。提出用ファイル名か証拠番号のどちらかを直してください。意図どおりならそのまま作成できます |
| 「上限を超えます」と出る | mints は一度のアップロードが 200MB までです。何回かに分けてアップロードしてください |
| 図面がA3より大きい | A3に縮小して出力します。縮小すると読み取れない図面は、紙提出等をご検討ください（読み込み時と確認画面で警告が出ます） |
| プレビューの表示が元のPDFと少し違う | 表示のための処理です。**書き出されるPDFの中身は元のまま**です |

分からないことは、画面右上の「**ヘルプ**」にも同じ説明が入っています。

## 9. ご意見・不具合のお知らせ

使ってみて気づいたことを教えてください。GitHub の「**Issues**」（https://github.com/lapi-clerk/LegalLeaves/issues）で受け付けています。

### 特に見ていただきたい点

- [ ] **提出用ファイル名**が、事務所の慣行どおりになっているか
- [ ] **証拠番号スタンプの位置・大きさ**が実務上おかしくないか
- [ ] **証拠説明書の下書き**が、どのくらい手直しで済むか
- [ ] 説明書を読まずに、**画面だけ見て操作できたか**（できなかった箇所はどこか）
- [ ] 途中で**手が止まった場面**があったか

### 報告していただきたいこと

うまくいかなかったときは、次を教えていただけると助かります。
（Issues に書いた内容は**誰でも見られます**。）

1. **どの画面で**（1 読み込み／2 照合／3 確認／4 出力／5 完了）
2. **何をしたら**
3. **どうなったか**（画面のスクリーンショットがあれば一番助かります）

> **依頼者のファイルそのものは、絶対に載せないでください。**
> スクリーンショットを載せる場合も、依頼者名・事件番号・ファイル名・フォルダ名が写り込んでいないかご確認ください。
> 再現に必要なら、同じ形のダミーファイル（架空の名前・番号）で試していただけると助かります。
