# タイムスタンプ帯の位置を測る（A4横・A3が未確認）

> 目的: mints提出後に付く裁判所のタイムスタンプ帯が、**A4横・A3縦・A3横**でどこに入るかを
> 確かめる。判明したら証拠番号の位置と干渉警告を正しく直せる（→ `docs/fix-backlog.md` の FB-6b）。

## いまの状況

| 用紙 | 帯の位置 | 状態 |
| --- | --- | --- |
| **A4縦** | 上端から **8〜19mm**、左 **31mm** 〜 右端から **11mm**、**1ページ目のみ** | ✅ 実測済み（FB-6） |
| A4横 | 不明 | ❌ 未確認 |
| A3縦 | 不明 | ❌ 未確認 |
| A3横 | 不明 | ❌ 未確認 |

**A4縦の値をそのまま他の用紙に当てはめてはいけません。** 考えられるのは

- (a) 用紙の向きに関わらず、紙の上端から**物理的に同じ位置**（8〜19mm）
- (b) 用紙サイズに**比例した位置**
- (c) そのどちらでもない

のいずれかで、どれかは提出してみないと分かりません。

## 測るのに必要なもの

1. **提出前**のPDF（楽々mintsが出力したもの）
2. **提出後**のPDF（mintsからダウンロードした、帯が付いた状態のもの）

同じファイルの前後を揃えるのが重要です（別のファイル同士では比較になりません）。

## 測り方

### 方法A: 付属のツールで測る（おすすめ・数値だけ出ます）

事務所のPCで、このリポジトリのフォルダを開いて次を実行します。

```bash
node tools/measure-timestamp-band.js "提出前.pdf" "提出後.pdf"
```

2つのPDFを重ね合わせて**差が出た場所＝帯**を検出し、位置をmmで表示します。
**ファイルは外部に送信されません。** 出力されるのは数値だけなので、
その数値（下の「報告してほしい項目」）をそのままお知らせいただければ対応できます。

### 方法B: PDFビューアの計測機能で測る

Adobe Acrobat 等の「ものさし／計測」ツールで、紙の上端から帯の上端・下端までの距離を測ります。
表示倍率に影響されないよう、**mm単位で表示される計測機能**を使ってください。

## 報告してほしい項目

用紙ごとに、次の5つが分かれば十分です。

1. **用紙**（A4横 / A3縦 / A3横 のどれか）
2. 紙の**上端から帯の上端**まで（mm）
3. 紙の**上端から帯の下端**まで（mm）
4. 紙の**左端から帯の左端**まで（mm）と、**右端から帯の右端**まで（mm）
5. 帯が付いたのは**1ページ目だけ**か（2ページ目以降にも付いていないか）

> 帯の中の文字（事件番号や当事者名）は**不要**です。位置の数値だけで対応できます。

## 数値が届いたらやること（開発者向け）

1. `src/timestamp-zone.js` に用紙ごとの実測値を追加する（**帯の定義はこのファイルだけ**）。
2. 帯が (a) 物理位置で一定だった場合 → 証拠番号の位置を「用紙上端からの物理量」で決めるよう
   `pdf-engine.js` の `placeLabel` を変更し、`stampHitsTimestampZone`（`src/app-review.js`）と
   プレビューの帯表示（`src/app-preview.js`）も同じ物理量へ揃える（**3つ同時に変えないと
   プレビューと出力がずれる**）。
3. `test/stamp-output.test.js` の回転・横向きのケースに「帯より下」の判定を追加する
   （いまは位置を参考表示するだけで、帯の位置が未確定のため合否判定にしていない）。
4. 実際に出力して、朱色のスタンプ画素の位置を測り直す（`docs/fix-backlog.md` FB-6b の実測方法）。
